## 📌 Capstone Project – *Financial Data Analysis (Western Countries)*  

💰 A **comprehensive analysis of financial data** from Western countries using:  

✅ **SQL** → Extracting, cleaning, and preparing datasets  
✅ **Excel** → Advanced financial modeling & pivot reporting  
✅ **Power BI** → Interactive dashboards & visual storytelling  

### 🔍 Objectives  
- Analyze **GDP growth, inflation, trade balance, and financial indicators**  
- Identify **trends, risks, and investment opportunities**  
- Build **dashboards for stakeholders** to make informed decisions
